## 2. Archivos Locales en este Directorio

Para fines de archivo y respaldo en el entorno local de laboratorio, se conservan dos versiones del video:

1. **`Video Original.mp4`** (405 MB):  
   Archivo de grabación cruda capturado directamente con el software de pantalla. Durante la revisión posterior, identifiqué que el micrófono capturó la voz con un nivel de ganancia sumamente bajo, dificultando su comprensión a volumen estándar.
   
2. **`Video Audio Mejorado.mp4`** (35.8 MB):  
   Versión procesada con amplificación y normalización de volumen mediante la herramienta *videocandy.com*. Esta es la versión que subí a YouTube para asegurar que el profesor pueda escuchar cada una de mis explicaciones técnicas de forma clara y nítida.
